# Z-Score Calculator

This repository contains the source code for the following paper:

**Kuo, H.C., Chen, S.H., Chen, I.F., Cheng, W.I., Liu, S.F., Guo, M.M.H., Lin, Y.C., & Chen, Y.H. (2024). Novel Multiple Z-Score Models for Detection of Coronary Artery Dilation: Application in Kawasaki Disease. *Pediatric Rheumatology*, 22:108.** 

The web application implementing the Z-Score Calculator can be accessed here:

[Z-Score Calculator](https://worldstar.github.io/Z-ScoreCalculator/)
